# DiaryClone

DiaryClone is a planning-ready baseline for a new internal Android and iOS app. The official BMad Method v6.12.4 installation is in `_bmad/` and `.agents/skills/`.

## Build inputs

- `_bmad-output/planning-artifacts/` contains the product brief, PRD, UX `DESIGN.md` and `EXPERIENCE.md`, `CAPTURE-AUDIT.md`, architecture, initiative, and the finalized `epics.md` (5 epics and 19 stories).
- `docs/Stoic/flows/` contains the source-flow documentation and 369 screen captures used for visual comparison.
- `_bmad-output/implementation-artifacts/sprint-status.yaml` tracks every epic and story as backlog.

The app has no implementation source yet. Start with Story 1.1 in `epics.md` using `bmad-build`; it creates the Expo starter and the first working app route. The scope is an internal screen-comparison build. The captured Privacy wording is not an external-release privacy policy.
